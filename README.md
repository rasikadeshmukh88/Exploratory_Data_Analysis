In this repository, I performed Exploratory Data Analysis (EDA) on multiple datasets including Car Data, Movies Data, Shopping Trends Data, Thyroid Cancer Data, and the Iris Dataset. Each dataset was analyzed separately to understand data distribution, trends, correlations, and key insights using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. The project focuses on data cleaning, visualization, and extracting meaningful insights to support data-driven decision making. This repository demonstrates my practical understanding of data analysis and visualization techniques.
